# Daily Word — Catholic Mass Readings

A Next.js website that displays the daily Catholic Mass readings (from the USCCB) with AI-powered reflections generated by Claude. Readings auto-update at midnight CST every day.

---

## Quick Start

### 1. Install dependencies

```bash
npm install
```

### 2. Set up environment variables

Copy `.env.example` to `.env.local`:

```bash
cp .env.example .env.local
```

Fill in the values:

| Variable | Where to get it |
|---|---|
| `ANTHROPIC_API_KEY` | [console.anthropic.com](https://console.anthropic.com) |
| `KV_URL` etc. | Vercel dashboard → Storage → KV (see step 4) |
| `CRON_SECRET` | Any random string you make up |

### 3. Run locally

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

> **Note:** The first page load each day will fetch and analyze the readings live (takes ~15–20 seconds). Subsequent loads are instant from cache.

## Deploying to Vercel (Free)

### Step 1 — Push to GitHub

Create a new GitHub repo and push this project to it.

### Step 2 — Import to Vercel

1. Go to [vercel.com](https://vercel.com) and sign in (free account is fine).
2. Click **Add New → Project**.
3. Import your GitHub repo.
4. Click **Deploy** (it will fail — that's OK, we need to add storage first).

### Step 3 — Add Vercel KV Storage

1. In your Vercel project, go to **Storage** tab.
2. Click **Create Database → KV**.
3. Name it anything (e.g., `daily-readings-kv`).
4. Once created, click **Connect to Project**.
5. This automatically adds the `KV_URL`, `KV_REST_API_URL`, `KV_REST_API_TOKEN`, and `KV_REST_API_READ_ONLY_TOKEN` environment variables.

### Step 4 — Add remaining env variables

In your Vercel project → **Settings → Environment Variables**, add:

- `ANTHROPIC_API_KEY` — your Anthropic key
- `CRON_SECRET` — your chosen secret string

### Step 5 — Redeploy

Go to **Deployments → Redeploy**. Your site is now live!

## How It Works

| Feature | Details |
|---|---|
| **Readings source** | USCCB (United States Conference of Catholic Bishops) |
| **Auto-update** | Vercel Cron runs at 6:00 AM UTC = midnight CST |
| **AI analysis** | Claude (claude-sonnet) generates plain-English summary, key takeaways, historical context, and practical application for each reading |
| **Storage** | Vercel KV (Redis) caches all readings + analyses |
| **Calendar** | Click the current date to browse past readings |

## URL Structure

- `/` — Today's readings
- `/2026-06-27` — Readings for a specific date (YYYY-MM-DD)
- `/api/readings/2026-06-27` — Raw JSON API endpoint
- `/api/cron` — Protected endpoint called automatically at midnight
